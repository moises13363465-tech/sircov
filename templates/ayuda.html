Iniciar Sesión

Para acceder al sistema SIRCOV, sigue estos pasos:

  1. Ingresa tu nombre de usuario en el campo correspondiente.
  2. Ingresa tu contraseña en el campo de contraseña.
  3. Haz clic en el botón "Entrar al Sistema".
  4. Si olvidas tu contraseña, haz clic en el enlace "¿Olvidaste tu Contraseña?" para recuperarla.
  5. Si eres un nuevo usuario, consulta con el administrador para obtener una cuenta.

Una vez iniciada la sesión, serás redirigido al panel principal donde verás un saludo personalizado y el menú de opciones.

Recuperar Contraseña

Si has olvidado tu contraseña, puedes recuperarla respondiendo preguntas de seguridad:

  1. Ingresa tu nombre de usuario y correo electrónico registrado.
  2. Ingresa una nueva contraseña segura.
  3. Selecciona y responde tres preguntas de seguridad predefinidas (como el nombre de tu primera escuela o tu comida favorita).
  4. Haz clic en "Actualizar Credenciales".
  5. Si todo es correcto, podrás iniciar sesión con la nueva contraseña.

Para ver la contraseña mientras la escribes, haz clic en el icono de ojo junto al campo.

Registrar una Marca

Para agregar una nueva marca al sistema:

  1. Desde el menú lateral, selecciona "Registro de Marca".
  2. Ingresa el nombre de la marca (ej: Caterpillar).
  3. Añade una descripción detallada.
  4. Selecciona las categorías aplicables (como Maquinaria Pesada o Vehículos Livianos).
  5. Agrega modelos asociados haciendo clic en el botón "+" para añadir más campos.
  6. Carga un logo de la marca (PNG o JPG) haciendo clic en el área de carga.
  7. Haz clic en "Guardar Marca" para confirmar, o "Cancelar" para volver atrás.

Las marcas registradas se usarán al agregar equipos o maquinarias.

Agregar un Equipo o Maquinaria

El registro de un equipo se realiza en varios pasos:

Paso 1: Información Básica

  1. Selecciona el tipo de vehículo (ej: Camión).
  2. Elige la marca y modelo disponibles.
  3. Ingresa la cilindrada, sistema de combustión y odómetro actual.
  4. Haz clic en "Siguiente".

Paso 2: Identificación

  1. Ingresa la placa, número de motor, serial de chasis y año de fabricación.
  2. Haz clic en "Siguiente Paso: Mecánica".

Paso 3: Información Mecánica

  1. Ingresa detalles como potencia, torque, tipo de transmisión, número de ejes y ruedas (dependiendo de la categoría: liviana, pesada o maquinaria).
  2. Haz clic en "Finalizar Registro".

Usa los botones de "Volver" para corregir pasos anteriores.

Editar un Equipo

Para modificar un equipo existente:

  1. Desde la gestión de flota, selecciona el equipo y haz clic en "Editar".
  2. Cambia el estado (Operativo, En Mantenimiento, Fuera de Servicio).
  3. Añade o modifica observaciones técnicas.
  4. Haz clic en "Guardar Cambios" o "Cancelar" para volver.

Gestionar la Flota Vehicular

Para ver y administrar la flota:

  1. Desde el menú, selecciona "Flota Vehicular".
  2. Usa el buscador para filtrar por cualquier dato.
  3. En la tabla, revisa detalles como ID, tipo, marca, etc.
  4. Haz clic en "Ver" para detalles en una ventana emergente.
  5. Haz clic en "Editar" para cambiar estado u observaciones.
  6. Haz clic en "Eliminar" y confirma para remover el equipo.

Si no hay resultados, se muestra un mensaje indicándolo.

Agregar un Operador

El registro se divide en pasos:

Paso 1: Datos Personales

  1. Ingresa nombres, apellidos, cédula, teléfono, edad (entre 18 y 60), sexo y nivel de instrucción.
  2. Añade un resumen general (opcional).
  3. Haz clic en "Siguiente".

Paso 2: Licencia y Experiencia

  1. Selecciona el tipo de licencia y ingresa fechas de expedición y vencimiento.
  2. Ingresa años de experiencia y certificaciones (opcional).
  3. Haz clic en "Siguiente".

Paso 3: Asignación de Maquinarias

  1. Selecciona hasta 3 maquinarias disponibles (filtradas por tipo de licencia).
  2. Haz clic en "Registrar Operador".

Gestionar Operadores

Para administrar operadores:

  1. Desde el menú, selecciona "Operadores".
  2. Usa el buscador para filtrar.
  3. En la tabla, revisa datos como nombres, cédula, estado.
  4. Haz clic en "Ver" para detalles completos en una ventana.
  5. Haz clic en "Editar" para modificar (similar a agregar).
  6. Haz clic en "Eliminar" y confirma.

Agregar un Usuario

Para crear un nuevo usuario:

  1. Ingresa un nombre de usuario (6-10 caracteres alfanuméricos).
  2. Crea una contraseña segura (con letra, número y símbolo).
  3. Selecciona el rol (ej: admin).
  4. Ingresa correo electrónico.
  5. Selecciona y responde tres preguntas de seguridad.
  6. Haz clic en "Agregar Usuario".

Para ver la contraseña, usa el icono de ojo.

Editar un Usuario

Para modificar un usuario existente:

  1. Actualiza el nombre de usuario si es necesario.
  2. Modifica el rol, correo o respuestas a preguntas de seguridad.
  3. Haz clic en "Guardar Cambios" o "Cancelar".

La contraseña no se edita aquí; usa recuperación si es necesario.

Gestionar Usuarios

Para ver y administrar usuarios:

  1. Desde el menú, selecciona "Gestión de Usuario".
  2. Usa el buscador para filtrar.
  3. En la tabla, revisa usuario, rol, correo.
  4. Haz clic en "Editar" para modificar.
  5. Haz clic en "Eliminar" y confirma.

Generar un Reporte

Para crear un reporte de flota:

  1. Desde el menú, selecciona "Reporte".
  2. Usa filtros como marca, estado, año, tanque o potencia.
  3. La tabla se actualiza automáticamente con los resultados.
  4. Haz clic en "Imprimir Reporte" para generar una versión imprimible.

Los estados se muestran con colores para fácil identificación.

Configuración del Sistema

Solo disponible para administradores. Para configurar:

  1. Desde el menú, selecciona "Configuración".
  2. Elige una sección como Marcas y Modelos, Tipos y Subtipos, Logo o Historial de Impresiones.
  3. En cada sección, agrega, edita o elimina elementos (ej: agregar una nueva marca o subir un logo).
  4. Revisa el historial de impresiones para ver logs de reportes generados.
  5. Haz clic en "Imprimir Historial" para obtener una copia.

Navegar en el Panel de Inicio

Al iniciar sesión:

  1. Verás un saludo con tu nombre de usuario.
  2. Usa el menú lateral para acceder a opciones como Inicio, Flota Vehicular, Operadores, Gestión de Usuario, Reporte o Configuración (si eres admin).
  3. Para cerrar sesión, haz clic en "Cerrar Sesión" al final del menú.

En dispositivos móviles, usa el botón de menú para abrir el sidebar.
